Shiny Iris Dataset Prediction App
This repository contains a Shiny application that provides an interactive interface for predicting the species of iris flowers using the well-known Iris dataset. The application allows users to input values for various flower attributes (sepal length, sepal width, petal length, and petal width), and it predicts the species of the iris based on these inputs using a pre-trained model.

Features:
Interactive Interface: Users can input data via a slider input to modify flower characteristics such as sepal length, sepal width, petal length, and petal width.
Predictive Model: The app uses a pre-trained Random Forest model to predict the species of an iris flower based on the given inputs.
Reactive Output: The server processes the user inputs and provides real-time predictions, which are displayed immediately on the interface.
Documentation: The app includes clear documentation to help users understand how to use the app and what the predictions mean.

How to Run:
Clone or download this repository to your local machine.
Install the necessary R packages (shiny, randomForest, dplyr, etc.).
Open the app.R file in RStudio and run the app by clicking the "Run App" button.
